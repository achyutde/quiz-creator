CSV format

Header row required. Column names are case-insensitive. correct can be a letter (A–F) or the exact answer text. Leave option columns blank for fewer choices. Optional topic and section columns are supported — add a section column and the quiz groups questions into sections with a section filter.

question,option_a,option_b,option_c,option_d,correct,explanation,topic,section
"What is 2 + 2?","3","4","5","22","B","Simple addition.","Math","Warm-up"
"Capital of Canada?","Toronto","Ottawa","Vancouver","Montreal","B","Ottawa is the capital.","Geography","Warm-up"
